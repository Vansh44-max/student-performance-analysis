# Student Performance Analysis and Visualization

## About the Project
This project analyzes student academic performance using Python and presents the results through interactive visualizations.

## Technologies Used
- Python
- Pandas — data handling and analysis
- NumPy — numerical operations and pass/fail classification
- Plotly Express — interactive charts
- Plotly Graph Objects — customized line charts

## Features
- Student marks and attendance dataset
- Average marks, percentages, grades, and pass/fail status
- Interactive bar charts and line charts
- Attendance vs. performance scatter plot
- Histogram and box plot for marks distribution
- Branch-wise performance comparison
- Student search by name
- Class average, highest and lowest performers, and pass percentage

## How to Run
1. Open the project in Google Colab or a Python environment.
2. Install the required libraries:
   `pip install pandas numpy plotly`
3. Run the Python code.
4. View the charts and class analysis.

## Note
This project currently uses sample student data. The percentage is calculated as the average of Python, DBMS, and Maths marks, assuming each subject is out of 100.
